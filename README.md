# Bible in a Year

A private study companion for the 2025 Bible in a Year podcast. Django + Django Ninja, PostgreSQL, and React.

## Scope

- The attached official 365-day reading plan supplies readings and timeline colors.
- Only podcast episodes whose publisher date falls in calendar year 2025 are eligible, including introductions and supplementary episodes.
- Full timestamped transcripts, commentary-only transcripts, lightly edited commentary, Scripture, summaries, audio outlines, and private notes/journals.
- Accounts are provisioned from the CLI; completion timestamps and listening progress belong to each user.
- Initial acceptance run: **one day only**. Bulk podcast import is not authorized yet.

Implementation and deployment instructions will be added as the app is completed. Deployment follows the isolated systemd/Gunicorn/Nginx pattern used by Carnival, with PostgreSQL.
